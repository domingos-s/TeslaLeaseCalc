# Lease Mileage Tracker PWA

A small installable PWA for tracking lease mileage against a total lease allowance.

## Features
- Lease setup flow: make, model, start date, duration, total mileage allowance, current mileage
- Calculates allowed mileage to date
- Shows under / tight / over status
- Calculates remaining miles, remaining daily pace, and projected end mileage
- Stores data locally in the browser via localStorage
- Offline support through a service worker

## Deploy on GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to Settings > Pages.
3. Set the branch to `main` and folder to `/root`.
4. Open the generated GitHub Pages URL.
5. On Android or iOS, use “Add to Home Screen.”
